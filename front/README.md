# Frontend Module

Aplicacao React para live view, dashboard operacional e visualizacao de metricas.

## Organizacao

- `package.json`: scripts e dependencias do app.
- `index.html`: HTML base usado pelo Vite.
- `src/main.tsx`: ponto de entrada React.
- `src/App.tsx`: composicao inicial da aplicacao.
- `src/components/`: componentes reutilizaveis.
- `src/pages/`: telas do produto.
- `src/services/`: clientes HTTP/WebSocket/WebRTC.
- `src/styles/`: estilos globais.

## Execucao

```powershell
npm install
npm run dev
```

App local: `http://localhost:5173`
